# Matplotlib Pyplot Tutorial Notebook

This repository contains a Jupyter Notebook that serves as an introduction to the `matplotlib.pyplot` interface in Python. The notebook is designed to help beginners understand the basics of plotting and visualization using `matplotlib`, one of the most popular plotting libraries in Python.

## Contents

- **notebooks/matplotlib.ipynb**:  
  The main tutorial notebook, which covers:
  - Introduction to Pyplot
  - Basic plotting with `plt.plot`
  - Formatting plot styles (markers, lines, colors)
  - Using NumPy arrays for plotting
  - Plotting with keyword strings (e.g., Pandas DataFrames)
  - Plotting with categorical variables (bar, scatter, and line plots)

## Getting Started

### Prerequisites

- Python 3.10 or higher is recommended
- Jupyter Notebook or JupyterLab
- Required Python packages:
  - `matplotlib`
  - `numpy`
  - (Optional) `pandas` for working with DataFrames

You can install the requirements using pip:

```bash
pip install matplotlib numpy pandas
```

### Running the Notebook

1. Clone this repository:
    ```bash
    git clone https://github.com/Saloni1999-star/laughing-couscous.git
    cd laughing-couscous
    ```
2. Launch Jupyter Notebook or JupyterLab:
    ```bash
    jupyter notebook
    ```
3. Open `notebooks/matplotlib.ipynb` and follow along with the tutorial.
